# COMO RODAR O PROJETO

1. Instale o XAMPP
2. Coloque a pasta dentro de:
   htdocs/coser

3. Crie o banco no phpMyAdmin:

CREATE DATABASE coser_db;

4. Importe o arquivo:
   database.sql

5. Acesse:
   http://localhost/coser

# O QUE FOI CORRIGIDO

- Imagens do checkout
- Segurança do PHP
- Tratamento de erros
- Conexão com banco
- Melhorias no backend
